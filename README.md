# Лабораторная работа № 3. Системы искусственного интеллекта

Локальное приложение для оценки покупательской способности клиентов автосалона. Оно обучает дерево решений, проверяет его на отложенной выборке и объясняет прогноз для нового клиента. Синтетические данные и прогнозы предназначены для учебной демонстрации.

## Установка и запуск

Нужен Python 3.10 или новее. Версии зависимостей проверены на Python 3.12.6.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1
```

В Windows PowerShell используйте `py -3 -m venv .venv` и `.venv\Scripts\Activate.ps1` вместо первых двух команд. Откройте [приложение в браузере](http://127.0.0.1:8501). Для остановки сервера нажмите Ctrl+C. После установки зависимостей приложение работает локально.

## Сценарий демонстрации

1. В разделе «Данные» нажмите «Загрузить демо-набор». Проверьте, что показано 1 200 записей, три класса и число записей с пропуском стажа.
2. Нажмите «Перейти к обучению», оставьте настройки по умолчанию и нажмите «Обучить дерево». Сравните четыре метрики по 240 отложенным записям. У матрицы строки соответствуют фактическим классам, столбцы — прогнозам. Откройте «Структура дерева» и измените глубину схемы.
3. Откройте «Оценка клиента». Введите доход 140 000 ₽/мес., обязательные расходы 65 000 ₽/мес., текущие платежи 10 000 ₽/мес., стаж 48 месяцев, взнос 500 000 ₽, цену 2 400 000 ₽ и выберите «Кредит». Нажмите «Оценить клиента». Дерево с настройками по умолчанию покажет высокую покупательскую способность и путь по фактическим условиям.
4. Поставьте взнос выше цены и повторите оценку. Исправьте взнос и отправьте форму ещё раз.
5. В разделе «Обучение и проверка» нажмите «Сохранить сводку», затем «Скачать CSV». Измените глубину дерева и повторите обучение, чтобы сравнить метрики.
6. Для проверки импорта выберите файл CSV в разделе «Данные». Файл без обязательных столбцов вызовет сообщение об ошибке. Смена источника очищает активный результат, и следующий набор нужно обучить заново.

## Формат CSV

Кодировка UTF-8, разделитель — запятая, десятичный разделитель — точка. Порядок столбцов произвольный. Заголовок обязателен.

| Столбец | Формат и смысл |
| --- | --- |
| `client_id` | Необязательный обезличенный идентификатор |
| `monthly_income` | Доход, ₽/мес. |
| `monthly_expenses` | Обязательные расходы, ₽/мес., без платежей из следующего столбца |
| `existing_monthly_payments` | Платежи по действующим обязательствам, ₽/мес. |
| `employment_months` | Стаж работы, целое число месяцев |
| `down_payment` | Первоначальный взнос, ₽ |
| `target_car_price` | Цена автомобиля, ₽ |
| `purchase_method` | `cash` (полная оплата), `credit` (кредит), `lease` (лизинг) |
| `ability_class` | Целевая метка `low`, `medium` или `high` |

Цена положительна, взнос не больше цены. Доход, расходы, платежи, стаж и взнос неотрицательны. В обучающем CSV допускается пустой стаж. Конвейер заполнит пропуск медианой по известным значениям в train. Если в train стаж нигде не указан, приложение предложит дополнить набор. В форме оценки обязательны все семь признаков.

```csv
client_id,monthly_income,monthly_expenses,existing_monthly_payments,employment_months,down_payment,target_car_price,purchase_method,ability_class
D0001,140000,65000,10000,48,500000,2400000,credit,high
```

Одна строка показывает формат. Для разбиения нужны минимум два класса, минимум две записи каждого представленного класса и достаточно объектов, чтобы все классы попали в обе выборки.

## Учебная разметка и эксперимент

Демо-набор `input/clients.csv` воспроизводится скриптом `input/generate_clients.py` с зерном 42. Для повторной генерации переместите существующий CSV и выполните `python input/generate_clients.py`. В демо-наборе свободный месячный остаток равен `F = max(0, monthly_income - monthly_expenses - existing_monthly_payments)`, коэффициент доступности равен `K = (down_payment + 36 × F) / target_car_price`. Классы определяются границами `K < 0.8` (низкая), `0.8 ≤ K < 1.2` (средняя) и `K ≥ 1.2` (высокая). Горизонт 36 месяцев и пороги приняты для учебного эксперимента. Для своего CSV подготовьте собственные метки заранее. В классификатор поступают семь исходных признаков.

Приложение сначала делит данные со стратификацией по классам, затем обучает заполнение стажа, one-hot-кодирование способов оплаты и дерево на train. Глубина схемы меняет только видимое число уровней. Accuracy — доля правильных прогнозов на test. Macro precision, recall и F1 дают каждому представленному классу одинаковый вес. На демо-наборе отчёт показывает, насколько дерево воспроизводит синтетическую разметку.

При настройках по умолчанию (80/20, `random_state=42`, `gini`, глубина до 6) получены accuracy **0,7125**, macro precision **0,6647**, macro recall **0,6700** и macro F1 **0,6665**. Модель правильно определила 26 из 61 записей среднего класса. Чаще всего средний класс ошибочно принимался за низкий (25 записей), что видно в матрице.

## Модули и выходные файлы

- `app.py` — страницы Streamlit и состояние текущей сессии
- `data_processing.py` — чтение, валидация, разбиение и преобразователь признаков
- `model.py` — обучение Pipeline, сохранение и прогноз
- `evaluation.py` — метрики и матрица ошибок
- `visualization.py` — графики matplotlib и реальные условия перехода между узлами
- `export.py` — дата, параметры, размеры, признаки, классы и метрики в одной строке CSV

После успешного обучения приложение записывает Pipeline в `artifacts/model.joblib`. Кнопка «Сохранить сводку» создаёт `reports/experiment_summary.csv`, а «Скачать CSV» скачивает те же данные в браузере. Сводка содержит только параметры и агрегаты эксперимента. Исходный CSV открывается для чтения.
